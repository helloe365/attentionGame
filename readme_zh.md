# 注意力训练

一个面向日常专注力练习的轻量训练应用，提供舒尔特方格、认知干扰任务、多目标追踪和本地训练记录。项目当前包含微信小程序源码，以及一份可直接部署的 H5 静态版本。

## 功能

### 舒尔特方格

- **练习**：按从小到大的顺序点击，点过的格子会变暗。
- **经典**：按顺序完成整盘。
- **反转**：从大到小点击；字母规格支持从 Z 到 A 或从 z 到 a。
- **挑战**：按顺序完成，点错一次立即结束。
- **疯狂**：每次点对后重新打乱棋盘。
- **速算**：计算算式结果并点击对应答案。
- **耐心**：在限定时间内反复完成 5×5 棋盘，记录完成轮数。

支持 3×3 至 9×9 数字棋盘，以及 A–Z、a–z 字母棋盘（速算模式使用数字棋盘）。

### 认知训练

- **斯特鲁普（Stroop）**：识别文字颜色，抵抗文字含义干扰。
- **西蒙效应（Simon）**：按颜色作答，忽略刺激出现的位置。
- **侧翼干扰（Flanker）**：只判断中间箭头，忽略两侧箭头。
- **反应抑制（Go/No-Go）**：圆形出现时点击，方形出现时忍住不点。

### 多目标追踪

记住高亮目标，观察小球移动后选出目标。支持 2、4、8 轮，并可选择需要追踪的目标数量。

### 记录与统计

- 保存每次训练的成绩、耗时、正确数、错误数和完成状态。
- 支持按训练类型、模式和规格筛选记录。
- 纪录和统计按训练模式及规格分别计算。
- 数据保存在设备本地，不需要登录或远程服务。

## 快速开始

### 微信小程序

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 导入本仓库目录。
3. 将小程序目录设置为 `miniprogram/`（项目配置已通过 `project.config.json` 指定）。
4. 使用 TypeScript 编译并在模拟器或真机预览。

项目的主要配置位于 `project.config.json`，页面入口位于 `miniprogram/app.json`。

### H5 静态版本

`xiaohongshu-dist/` 是可直接部署的静态目录。将该目录作为网站根目录托管，或在本地使用任意静态文件服务器打开 `index.html`：

```bash
cd xiaohongshu-dist
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 项目结构

```text
.
├── miniprogram/                 # 微信小程序源码
│   ├── core/                    # 训练模型、规则、记录与本地存储
│   ├── components/              # 可复用组件
│   ├── pages/                  # 首页、训练、记录等页面
│   └── assets/                 # 图片资源
├── xiaohongshu-dist/            # H5 静态发布目录
├── project.config.json          # 微信开发者工具项目配置
└── .gitignore
```

核心训练逻辑位于 `miniprogram/core/`，界面页面位于 `miniprogram/pages/`。训练过程中切换到后台或锁屏会中断当前局。

## 技术说明

- 微信小程序原生页面与组件
- TypeScript
- WXML / WXSS
- Canvas（多目标追踪）
- 浏览器端静态 H5 资源

本项目没有依赖后端 API；训练记录使用小程序本地存储或 H5 本地存储。

## 隐私与数据

项目默认仅在当前设备保存训练记录和设置，不上传训练数据。清除小程序或浏览器本地数据会同时删除对应记录。
